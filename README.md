# RPC Maker

Утилита для установки Discord Rich Presence. Работает из коробки —
не нужно создавать своё приложение на Discord Developer Portal.

## Что умеет

- Заголовок (Details) и вторая строка (State)
- До двух кнопок со ссылками
- Таймер "играет с..."
- Иконка и имя приложения берутся из вшитого Application ID

## Использование

1. Скачай `RPCMaker-1.0.exe` из раздела Releases.
2. Запусти установщик, пройди стандартную установку.
3. Запусти RPC Maker из меню Пуск.
4. Заполни поля:
   - Заголовок (Details) — обязательное поле
   - Детали (State) — необязательно
   - Кнопки — необязательно, максимум две
5. Нажми "Ставлю активность...".
6. Открой Discord — активность появится в профиле.

Если Windows SmartScreen блокирует запуск — нажми
"Подробнее" → "Выполнить в любом случае". Установщик не подписан
сертификатом, но исходники открыты.

## Сборка

Требуется JDK 17+ и Gradle 8.x.

    gradle shadowJar

Собранный `.jar` появится в `build/libs/`.

Для сборки `.exe`-установщика нужен jpackage (входит в JDK 17+)
и WiX Toolset v3 (только Windows).
